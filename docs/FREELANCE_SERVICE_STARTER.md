# Freelance Analytics Service — Starter Offer

This page is a practical first-service definition for independent client work. It describes services the portfolio can demonstrate; it does not claim paid client history.

## Positioning

**Data Cleaning, Excel/SQL Analysis & Power BI Dashboards**

I help small businesses and teams turn messy spreadsheets and operational data into clean reports, useful KPIs, and easy-to-understand dashboards.

**Tools:** Excel, MySQL, Python (Pandas), Power BI, DAX, Power Query.

## Services to offer first

### 1. Excel data cleaning and reporting
- Remove duplicate rows after agreeing on the correct unique key.
- Identify and report missing values, invalid dates, inconsistent categories and outliers.
- Standardize columns and prepare a clean, documented workbook/CSV.
- Build PivotTables, summary reports and charts when requested.

### 2. SQL data analysis
- Write SELECT, JOIN, GROUP BY, CASE, CTE and window-function queries.
- Create reusable views and KPI summaries.
- Investigate data-quality issues and reconcile totals against agreed source data.

### 3. Power BI dashboard
- Prepare and model the provided data.
- Build KPI cards, trend charts, category breakdowns and slicers.
- Add drill-through only when it helps answer a real business question.
- Provide a short handover guide and explain metric definitions.

### 4. Python data preparation
- Use Pandas to clean and transform CSV/Excel extracts.
- Create repeatable scripts and validation summaries.
- Deliver cleaned outputs and source code, with run instructions.

## Starter scope and pricing guide

These are suggested introductory quotes in INR, not fixed market rates. Quote only after checking row count, file quality, number of sources, deadline and revision expectations.

| Service | Suggested starter quote | Typical scope |
|---|---:|---|
| Small spreadsheet cleanup | ₹800–₹1,500 | One file, up to ~10k rows, agreed checks |
| Excel summary report | ₹1,000–₹2,000 | One workbook, PivotTables/charts |
| SQL analysis task | ₹1,500–₹3,000 | Defined questions, queries and findings |
| Basic Power BI dashboard | ₹2,500–₹5,000 | One dataset/model, up to 2 report pages |
| Python cleaning script | ₹1,500–₹3,500 | One repeatable CSV/Excel pipeline |

Do not promise these prices for every job. Increase the quote for multiple sources, complex joins, unclear data, many pages, urgent delivery, or ongoing support. Agree on scope and payment milestones in writing before starting.

## Delivery checklist

Every project should include the agreed subset of:
- Cleaned output file(s).
- Source Excel / SQL / Python / PBIX files as applicable.
- Data-quality summary: rows received, rows retained, duplicates, missing values and transformations.
- KPI dictionary with formulas, filters and units.
- Dashboard PDF/export or screenshots, if requested.
- Short README / handover notes.
- Known limitations and assumptions.

Never silently delete data. Preserve the raw source, document exclusions, and get approval for ambiguous business rules. Do not upload client data to public GitHub or portfolio examples without written permission and anonymization.

## Client discovery questions

1. What decision or business problem should the analysis support?
2. Which files/tables are available, and what does one row represent?
3. What are the key IDs and date fields?
4. Which KPIs and filters are required? How are they defined?
5. Are there known data issues or exclusions?
6. What output is expected: cleaned file, Excel report, SQL, Python script, Power BI PBIX, PDF?
7. What is the deadline, review process and budget?
8. Can sample or anonymized data be shared before final quotation?

## First-client workflow

1. Ask for an anonymized sample and business questions.
2. Confirm row grain, keys, definitions, output, deadline and price.
3. Agree on scope, revisions, payment and data handling in writing.
4. Preserve a read-only raw copy and work on a separate copy.
5. Validate totals and edge cases before building visuals.
6. Share a preview for one consolidated feedback round.
7. Deliver agreed editable files and handover notes.
8. Ask for permission before using any result, screenshot or testimonial publicly.
